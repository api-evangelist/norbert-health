# Norbert Health

> Norbert Health, Inc. builds "Norbert", an autonomous care manager for nursing homes and
> rehabilitation facilities: a robot-mounted or tabletop AI module that plans rounding
> schedules, contactlessly senses patient vitals and behavior, and writes clinical notes.
> The device is an investigational device, limited by US federal law to investigational
> use pending FDA clearance.

IMPORTANT FOR AGENTS: Norbert Health publishes **no public API**. There is no developer
portal, no API reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK, no MCP server, and
no agent card. The host `api.norberthealth.com` exists but is a private AWS API Gateway
backing the NORBERT Health mobile app; it returns HTTP 403 `{"message":"Forbidden"}` on
every path to an anonymous caller. Do not attempt to construct calls against it. The only
route to an integration is a human sales conversation
(mailto:info@norberthealth.com).

## Product capability surface (from the public site, not from a contract)

- Sensing: contactless pulse and respiratory rate; room presence and activity patterns;
  environmental and room-level trend monitoring; mobility and gait assessment; cognitive
  and behavioral assessment via vocal biomarkers; guided patient-reported outcome check-ins.
- Understanding: per-patient routine and preference memory; interaction complexity adapted
  to cognitive level; patient-preferred language; personalized prompt tone and timing.
- Action: task assignment with due times and priorities; role-specific alerts and
  escalation routing; structured clinical note generation and EMR integration.
- Deployment: robot-mounted or tabletop; runs on existing facility Wi-Fi; a web console
  for administrators.

## Integration reality

- EMR/EHR integration is advertised ("EMR notes and encounter logging", "Connects to your
  care management and medical records system") but **no standard is named** — no FHIR,
  HL7 v2, SMART on FHIR or USCDI reference, and no integration documentation.
- "HIPAA-ready systems" is claimed in marketing copy. No attestation, BAA, SOC 2 report,
  ISO 27001 certificate, or trust center is published.
- Contact: info@norberthealth.com (demos), support@norberthealth.com (support). There is
  no security.txt and no vulnerability-disclosure contact.
